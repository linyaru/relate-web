Bolt Server

cypherlite-bolt runs the embedded engine behind a Bolt transport, so the official Neo4j drivers can connect and run openCypher. Bolt is a transport, not Neo4j Cypher parity: the language contract stays the openCypher TCK. Neo4j-specific clauses fail as syntax or semantic errors.

Getting the binary​

cypherlite-bolt is a separate binary and is not part of the cypherlite install: install.sh and the release assets ship only the cypherlite CLI, and the CLI has no bolt subcommand. Build the server from a source checkout:

cargo build --release -p cypherlite-bolt
./target/release/cypherlite-bolt --help

Or install it from the checkout with cargo install --path crates/cypherlite-bolt. Prebuilt cypherlite-bolt release artifacts are not published yet.

Run it​

cypherlite-bolt --bind 127.0.0.1:7687 --uri :memory:
cypherlite-bolt --uri ./graph --memory-limit 1gib
cypherlite-bolt --help

From a source checkout without installing, cargo run -p cypherlite-bolt -- … is equivalent.

FlagDefaultMeaning
--bind <ADDR>127.0.0.1:7687Listen address
--uri <URI>:memory:Database URI (:memory:, a directory, or a .cl bundle / file://)
--wal-dir <PATH>unsetLocal WAL directory (ignored for :memory:)
--checkpoint-interval-secs <N>300 (CYPHERLITE_CHECKPOINT_INTERVAL_SECS)Seconds between timed checkpoints when the WAL has work. 0 disables. Persistent URIs only.
--memory-limit <SIZE>unset (CYPHERLITE_MEMORY_LIMIT; 0/omit = unlimited)Live graph + index logical cap. SIZE is bytes, or an integer plus mb/mib/gb/gib. Exceeding it fails a growing write with capacity exceeded: used=… limit=….

Connect from a driver​

The server speaks Bolt 4.4 (handshake magic 0x6060B017) with PackStream v1. Auth is ignored in this version — it succeeds with server: "CypherLite/<version>".

# pip install neo4j  (driver v6)
from neo4j import GraphDatabase

with GraphDatabase.driver("bolt://127.0.0.1:7687", auth=None) as driver:
    with driver.session() as session:
        print(session.run("RETURN 1 AS n").single()["n"])

RETURN 1 AS n is the smoke test the server's contract tests run with the official Python driver.

Protocol surface​

MessageSupport
HELLOExtra user_agent; auth ignored in v1
RUNRUN cypher [params], then PULL / DISCARD
PULLRECORD(s), then SUCCESS with t_last (record-streaming ms)
DISCARDSUCCESS
RESETClears failed state; rolls back an open transaction
GOODBYEClose
BEGINStarts an explicit transaction on the session connection. Nested BEGIN fails already in a transaction.
COMMITOne WAL commit of that transaction. Without BEGIN fails no transaction.
ROLLBACKDiscards uncommitted writes. Without BEGIN fails no transaction.

Not supported: routing (ROUTE), Bolt 5+ logon, reactive.

A write-write conflict is a FAILURE with message write-write conflict; the server does not retry — retry in the caller (ADR-0017).

Full contract: docs/api/bolt/spec.md.
