relate ships 194 function signatures under 176 names, the rows `SHOW FUNCTIONS` returns, plus six more behind preview opt-ins. This page lists each one by category with its signature as `SHOW FUNCTIONS` prints it, what it returns, and a note on the edge cases. A row that differs from its catalog signature says so. Rows that name several functions (the trigonometric, hyperbolic, clock and `*.truncate` rows), the `format(value :: …, pattern :: STRING)` row, and the `[, pattern :: STRING]` form of the GQL temporal names each condense several catalog signatures into one. The cells run on relate's WebAssembly (WASM) build, which runs the same engine as the CLI and the clients.

## Synopsis

```text
<name>(<argument>, …)
<namespace>.<name>(<argument>, …)
SHOW FUNCTIONS [YIELD <column>, …] [WHERE <predicate>] [RETURN …]
```

| Rule | Detail |
| --- | --- |
| Names | Case-insensitive: `TOUPPER('a')` and `toUpper('a')` are the same call |
| `null` arguments | A scalar function given `null` returns `null`, unless its row says otherwise |
| Unknown name | `syntax error: UnknownFunction: unknown function <name>()` |
| Wrong arity | `syntax error: InvalidNumberOfArguments: <name>() …`, for example ``coalesce() requires at least one argument, got 0`` |
| `SHOW FUNCTIONS` columns | `name`, `category`, `description`, `signature`, `isBuiltIn`, `argumentDescription`, `returnDescription`, `aggregating`, `isDeprecated`, `deprecatedBy` |
| Deprecated functions | Under `EXPLAIN`, a call raises notification `01N01` with the replacement ([notifications](/docs/reference/cypher/notifications)) |

```cypher run name=catalog
SHOW FUNCTIONS YIELD name, category, signature
WHERE name STARTS WITH 'vector'
RETURN name, category, signature ORDER BY name
```

## Graph element functions

These functions read a :term[node]{id=node}, a :term[relationship]{id=relationship} or a :term[path]{id=path}: its labels or type, its :term[properties]{id=property}, its end nodes and its :term[element id]{id=element-id}.

| Signature | Returns | Notes |
| --- | --- | --- |
| `elementId(input :: NODE \| RELATIONSHIP) :: STRING` | The element id | `4:relate:n<k>` for a node, `5:relate:r<k>` for a relationship |
| `id(input :: NODE \| RELATIONSHIP) :: INTEGER` | The integer id | Deprecated; the catalog names `elementId` as the replacement |
| `db.nameFromElementId(elementId :: STRING) :: STRING` | The namespace of an element id | `neo4j` for the data namespace |
| `labels(input :: NODE) :: LIST<STRING>` | The node's labels | — |
| `type(input :: RELATIONSHIP) :: STRING` | The relationship type | — |
| `keys(input :: NODE \| RELATIONSHIP \| MAP) :: LIST<STRING>` | The property names, or a map's keys | In sorted order |
| `properties(input :: NODE \| RELATIONSHIP \| MAP) :: MAP` | Every property as a map | A map argument returns the map |
| `startNode(input :: RELATIONSHIP) :: NODE` | The start node | — |
| `endNode(input :: RELATIONSHIP) :: NODE` | The end node | — |
| `nodes(input :: PATH) :: LIST<NODE>` | The path's nodes, in order | — |
| `relationships(input :: PATH) :: LIST<RELATIONSHIP>` | The path's relationships, in order | — |
| `length(input :: PATH) :: INTEGER` | The number of relationships in the path | — |
| `path_length(input :: PATH) :: INTEGER` | The number of relationships in the path | GQL name of `length` |

The cells from here on run on the shared example graph:

```cypher run name=seed
CREATE (ada:Person {name: 'Ada', role: 'engineer'}),
       (grace:Person {name: 'Grace', role: 'engineer'}),
       (noor:Person {name: 'Noor', role: 'maintainer'}),
       (relate:Project {name: 'relate', language: 'Rust'}),
       (tck:Project {name: 'opencypher-tck', language: 'Gherkin'}),
       (ada)-[:WORKS_ON {since: 2024}]->(relate),
       (grace)-[:WORKS_ON {since: 2023}]->(relate),
       (grace)-[:WORKS_ON {since: 2022}]->(tck),
       (noor)-[:MAINTAINS]->(relate),
       (ada)-[:KNOWS]->(grace)
```

```cypher run name=graph-elements
MATCH p = (a:Person {name: 'Ada'})-[r:WORKS_ON]->(proj)
RETURN labels(a) AS labels, type(r) AS type, keys(a) AS keys, properties(r) AS props,
       endNode(r).name AS ends_at, length(p) AS hops, size(nodes(p)) AS path_nodes,
       db.nameFromElementId(elementId(a)) AS namespace
```

## Conversion functions

| Signature | Returns | Notes |
| --- | --- | --- |
| `toString(input :: ANY) :: STRING` | The value as a string | Maps, lists and graph values render in display form (`{a: 1}`). A list literal fails at compile time with `syntax error: InvalidArgumentValue: toString()`; a list in a variable or property converts |
| `toStringOrNull(input :: ANY) :: STRING` | As `toString`, or `null` instead of an error | — |
| `toInteger(input :: BOOLEAN \| STRING \| INTEGER \| FLOAT) :: INTEGER` | The value as an integer | A float truncates toward zero; a string parses decimal, hexadecimal (`'0x1F'`), octal and `_` forms. A `BOOLEAN` argument fails with `type error: InvalidArgumentValue: toInteger()`, although the catalog lists it. A string outside the range fails with `NumberOutOfRange` |
| `toIntegerOrNull(input :: ANY) :: INTEGER` | As `toInteger`, or `null` | — |
| `toFloat(input :: STRING \| INTEGER \| FLOAT) :: FLOAT` | The value as a float | `'NaN'` and `'Infinity'` parse; other spellings are `null` |
| `toFloatOrNull(input :: ANY) :: FLOAT` | As `toFloat`, or `null` | — |
| `toBoolean(input :: BOOLEAN \| STRING \| INTEGER) :: BOOLEAN` | The value as a boolean | Strings `'true'` and `'false'` in any case; other strings give `null`. An integer is `false` only for `0` |
| `toBooleanOrNull(input :: ANY) :: BOOLEAN` | As `toBoolean`, or `null` | — |
| `toStringList(input :: LIST<ANY>) :: LIST<STRING>` | Each element as a string | A `null` element becomes `'null'` |
| `toIntegerList(input :: VECTOR \| LIST<ANY>) :: LIST<INTEGER>` | Each element as an integer | An element that does not convert becomes `null`; never fails for an element |
| `toFloatList(input :: VECTOR \| LIST<ANY>) :: LIST<FLOAT>` | Each element as a float | Same rule; also takes a vector |
| `toBooleanList(input :: LIST<ANY>) :: LIST<BOOLEAN>` | Each element as a boolean | Same rule |

```cypher run name=conversion
RETURN toString({a: 1}) AS display, toInteger(-3.9) AS truncated, toInteger('0x1F') AS hex,
       toIntegerOrNull('x') AS bad_int, toBoolean('TRUE') AS bool, toBoolean('yes') AS not_bool,
       toIntegerList(['1', 'x']) AS ints, toFloatList(vector([1, 2], 2, INT8)) AS from_vector
```

| --- | --- | --- |
| `point(input :: MAP) :: POINT` | A 2D or 3D point | The keys choose the coordinate system ([points](/docs/reference/cypher/types-and-values#points)) |
| `point.distance(from :: POINT, to :: POINT) :: FLOAT` | The distance between two points in one coordinate system | Euclidean for Cartesian points; meters for WGS-84 points, on a sphere of radius 6,378,140 m. Points in two different systems give `null` |
| `point.withinBBox(point :: POINT, lowerLeft :: POINT, upperRight :: POINT) :: BOOLEAN` | Whether the point is inside the box | A `POINT INDEX` serves this filter and `point.distance(…) < <bound>` ([geospatial](/docs/guides/cypher/geospatial)) |

```cypher run name=spatial
RETURN point.distance(point({x: 0, y: 0}), point({x: 3, y: 4})) AS cartesian,
       round(point.distance(point({latitude: 51.5, longitude: -0.1}), point({latitude: 48.86, longitude: 2.35}))) AS meters,
       point.withinBBox(point({x: 1, y: 1}), point({x: 0, y: 0}), point({x: 2, y: 2})) AS inside
```

## Vector functions

| Signature | Returns | Notes |
| --- | --- | --- |
| `vector(vectorValue :: STRING \| LIST<INTEGER \| FLOAT>, dimension :: INTEGER, coordinateType :: [INTEGER64, INTEGER32, INTEGER16, INTEGER8, FLOAT64, FLOAT32]) :: VECTOR` | A `VECTOR` value | The coordinate type is a bare keyword; the spellings are in [vectors](/docs/reference/cypher/types-and-values#vectors) |
| `vector.similarity.cosine(a :: VECTOR \| LIST<INTEGER \| FLOAT>, b :: VECTOR \| LIST<INTEGER \| FLOAT>) :: FLOAT` | Cosine similarity rescaled to 0 to 1 | `1.0` same direction, `0.5` orthogonal, `0.0` opposite; the score a cosine vector index reports |
| `vector.similarity.euclidean(a :: VECTOR \| LIST<INTEGER \| FLOAT>, b :: VECTOR \| LIST<INTEGER \| FLOAT>) :: FLOAT` | `1 / (1 + d²)`, where `d` is the Euclidean distance | `1.0` for identical vectors |
| `vector_distance(vector1 :: VECTOR, vector2 :: VECTOR, coordinateType :: [EUCLIDEAN, EUCLIDEAN_SQUARED, MANHATTAN, COSINE, DOT, HAMMING]) :: FLOAT` | The raw distance under the metric | Lower is closer for every metric; `DOT` is the negated dot product. Takes `VECTOR` values only |
| `vector_norm(vector :: VECTOR, vectorDistanceMetric :: [EUCLIDEAN, MANHATTAN]) :: FLOAT` | The distance from the origin | — |
| `vector_dimension_count(input :: VECTOR) :: INTEGER` | The dimensions | — |

The similarity functions take a vector or a plain list in each position. Arguments of different lengths fail with `type error: InvalidArgumentValue: vectors must have same dimensions`, and a `null` argument gives `null`.

```cypher run name=vector
WITH vector([0, 0], 2, INT8) AS origin, vector([3, 4], 2, INT8) AS v
RETURN vector.similarity.cosine([1, 0], [0, 1]) AS cosine, vector.similarity.euclidean([0, 0], [3, 4]) AS euclidean,
       vector_distance(origin, v, EUCLIDEAN) AS distance, vector_distance(origin, v, MANHATTAN) AS manhattan,
       vector_norm(v, EUCLIDEAN) AS norm, vector_dimension_count(v) AS dims
```

## Aggregating functions

An aggregating function reduces the rows of a group to one value; the other items of the `RETURN` or `WITH` are the grouping keys. `DISTINCT` before the argument aggregates each distinct value once, and `ALL` is the default.

| Signature | Returns | Notes |
| --- | --- | --- |
| `count(input :: ANY) :: INTEGER` | The number of values that are not `null` | `count(*)` counts rows, `null` included |
| `sum(input :: INTEGER \| FLOAT \| DURATION) :: INTEGER \| FLOAT \| DURATION` | The sum | `0` over no values; mixing numbers and durations fails |
| `avg(input :: INTEGER \| FLOAT \| DURATION) :: INTEGER \| FLOAT \| DURATION` | The mean | A float for integers; `null` over no values |
| `min(input :: ANY) :: ANY` | The smallest value | Across types, the type order of `ORDER BY` applies |
| `max(input :: ANY) :: ANY` | The largest value | Same rule |
| `collect(input :: ANY) :: LIST<ANY>` | The values as a list | `null` values are left out; `[]` over no values |
| `stDev(input :: FLOAT) :: FLOAT` | Sample standard deviation, divided by N − 1 | `null` over no values |
| `stDevP(input :: FLOAT) :: FLOAT` | Population standard deviation, divided by N | — |
| `percentileCont(input :: FLOAT, percentile :: FLOAT) :: FLOAT` | The percentile, interpolated | `percentile` from 0 to 1 |
| `percentileDisc(input :: INTEGER \| FLOAT, percentile :: FLOAT) :: INTEGER \| FLOAT` | The nearest value at the percentile | Returns a `FLOAT` for integer input: `2.0` |
| `collect_list(input :: ANY) :: LIST<ANY>` | Same as `collect` | GQL name |
| `stdev_samp(input :: FLOAT) :: FLOAT` | Same as `stDev` | GQL name |
| `stdev_pop(input :: FLOAT) :: FLOAT` | Same as `stDevP` | GQL name |
| `percentile_cont(input :: FLOAT, percentile :: FLOAT) :: FLOAT` | Same as `percentileCont` | GQL name |
| `percentile_disc(input :: INTEGER \| FLOAT, percentile :: FLOAT) :: INTEGER \| FLOAT` | Same as `percentileDisc` | GQL name |

Every aggregate but `count(*)` skips `null` values.

```cypher run name=aggregates
MATCH (p:Person)-[w:WORKS_ON]->(proj:Project)
RETURN proj.name AS project, count(*) AS people, collect(p.name) AS names,
       min(w.since) AS first, avg(w.since) AS mean, percentileDisc(w.since, 0.5) AS median
ORDER BY project
```

## Predicate functions

| Signature | Returns | Notes |
| --- | --- | --- |
| `all(variable :: VARIABLE IN list :: LIST<ANY> WHERE predicate :: ANY) :: BOOLEAN` | `true` when every element passes | `true` for an empty list |
| `any(variable :: VARIABLE IN list :: LIST<ANY> WHERE predicate :: ANY) :: BOOLEAN` | `true` when an element passes | `false` for an empty list |
| `none(variable :: VARIABLE IN list :: LIST<ANY> WHERE predicate :: ANY) :: BOOLEAN` | `true` when no element passes | — |
| `single(variable :: VARIABLE IN list :: LIST<ANY> WHERE predicate :: ANY) :: BOOLEAN` | `true` when exactly one element passes | — |
| `allReduce(accumulator :: VARIABLE = initial :: ANY, variable :: VARIABLE IN list :: LIST<ANY> \| reducer :: ANY, predicate :: BOOLEAN) :: BOOLEAN` | `true` when the predicate holds after every step | Stops at the first step that fails |
| `exists(input :: ANY) :: BOOLEAN` | `true` when the pattern has a match | Takes a pattern: `exists((a)-[:KNOWS]->())`. The property form `exists(n.prop)` fails with ``syntax error: InvalidPropertyExistence: the property existence syntax `exists(variable.property)` is no longer supported. Please use `variable.property IS NOT NULL` or `property_exists(...)` instead`` |
| `isEmpty(input :: STRING \| MAP \| LIST<ANY>) :: BOOLEAN` | `true` for `''`, `{}` and `[]` | — |
| `property_exists(element :: NODE \| RELATIONSHIP, propertyKeyName :: STRING) :: BOOLEAN` | `true` when the property is set | The key is written as a name, `property_exists(n, age)`; a string literal fails with `syntax error: parse error: PROPERTY_EXISTS() second argument must be a property name identifier` |

```cypher run name=predicates
MATCH (p:Person {name: 'Grace'})
RETURN exists((p)-[:WORKS_ON]->()) AS works, property_exists(p, role) AS has_role,
       property_exists(p, email) AS has_email, isEmpty([]) AS empty,
       all(x IN [2023, 2022] WHERE x > 2020) AS all_recent
```

## Path functions

| Signature | Returns | Notes |
| --- | --- | --- |
| `shortestPath(pathPattern :: PATH) :: PATH` | One shortest path for the pattern | In an expression, `null` when there is none |
| `allShortestPaths(pathPattern :: PATH) :: LIST<PATH>` | Every shortest path | — |

As `MATCH p = shortestPath(…)`, the same forms return one row per path; [patterns](/docs/reference/cypher/patterns) covers them and the `SHORTEST` path selector.

```cypher run name=paths
MATCH (a:Person {name: 'Ada'}), (t:Project {name: 'opencypher-tck'})
RETURN length(shortestPath((a)-[*]-(t))) AS hops, size(allShortestPaths((a)-[*]-(t))) AS paths
```

## Preview functions

These functions are off until `RELATE_PREVIEW` names their feature, and `SHOW FUNCTIONS` lists them only then. Off, a call fails with `syntax error: UnknownFunction: unknown function <name>()`. The WASM build has no process environment, so it cannot turn them on.

| Signature | Returns | Opt-in | Notes |
| --- | --- | --- | --- |
| `coll.zip(list1 :: LIST<ANY>, list2 :: LIST<ANY> ...) :: LIST<ANY>` | Per-index lists, to the longest input's length | `coll-zip` | Missing positions are `null`: `coll.zip([1, 2], ['a'])` is `[[1, 'a'], [2, null]]` |
| `coll.hasAnyOf(list :: LIST<ANY>, values :: LIST<ANY>) :: BOOLEAN` | `true` when any of `values` is in `list` | `coll-has` | An undecided result with a `null` element is `null` |
| `coll.hasAllOf(list :: LIST<ANY>, values :: LIST<ANY>) :: BOOLEAN` | `true` when every one of `values` is in `list` | `coll-has` | — |
| `coll.hasNoneOf(list :: LIST<ANY>, values :: LIST<ANY>) :: BOOLEAN` | `true` when none of `values` is in `list` | `coll-has` | — |
| `stddev_samp(input :: FLOAT) :: FLOAT` | Same as `stDev` | `gql-stddev-aliases` | `stdev_samp` needs no opt-in |
| `stddev_pop(input :: FLOAT) :: FLOAT` | Same as `stDevP` | `gql-stddev-aliases` | `stdev_pop` needs no opt-in |

With the opt-ins in the command's environment:

```bash verify
RELATE_PREVIEW=coll-zip,coll-has,gql-stddev-aliases relate --mode jsonl "RETURN coll.zip([1, 2], ['a']) AS zipped, coll.hasAnyOf([1, 2], [2]) AS any_of, coll.hasAllOf([1, 2], [1, 3]) AS all_of, coll.hasNoneOf([1, 2], [5]) AS none_of"
```

```text
{"all_of":false,"any_of":true,"none_of":true,"zipped":[[1,"a"],[2,null]]}
```
