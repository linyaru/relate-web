The envelope is the CLI's machine-readable result: one JSON object per result set, on one line. It holds `columns` and `columnTypes`, the `rows` as objects keyed by column, the planner's `notifications`, `truncated`, the statement's phase `timings` in milliseconds, and `planCache`, which says whether a cached plan served the statement. Under a :term[row cap]{id=row-cap} it also holds `rowCap`, with the rows kept and the total. An `EXPLAIN` or `PROFILE` adds the `plan`. Because `columns` is always present, an empty result still says what it would have held. The `timings` numbers change from run to run.

A failed statement prints an :term[error object]{id=error-object} instead, with the stderr message and the exit code unchanged. Agent mode never changes the envelope's shape.

```bash
relate --mode envelope "UNWIND [1, 2] AS x RETURN x"
```

```text
{"columnTypes":["INTEGER"],"columns":["x"],"notifications":[],"planCache":"miss","rows":[{"x":1},{"x":2}],"timings":{"elapsed_ms":0.454958,"execute_ms":0.265791,"lex_parse_ms":0.026625,"lower_ms":0.035207999999999996,"parse_ms":0.122333,"plan_ms":0.055292,"result_generation_ms":0.0005,"rewrite_ms":0.008624999999999999},"truncated":false}
```
