Python Library Reference

The cypherlite Python package embeds cypherlite::Database as a native extension module (built with PyO3 and maturin). Queries execute in-process — there is no subprocess, server, or network round-trip. Persistent paths are CypherLite directories containing a WAL and one snapshot codec (Parquet by default, or GraphData JSON).

The package offers two API styles:

APIEntry pointStyle
Connection/Cursorcypherlite.connect()sqlite3-style (DB-API 2.0 flavored)
Nativecypherlite.DatabaseDirect engine access, Arrow IPC via execute_arrow()

Installation​

When published, install from PyPI (neo4j-cypherlite; import cypherlite):

pip install neo4j-cypherlite
# optional Arrow IPC decoding
pip install neo4j-cypherlite[arrow]

Until the PyPI project is registered (trusted publishing on tagged releases), install from a checkout (requires the Rust toolchain):

cd crates/cypherlite-python
pip install maturin
maturin develop --release

Or, from the repository root, use the Make target (creates a virtualenv, installs maturin, and runs maturin develop):

make install-python
note

Legacy single-file GraphStore JSON and Lance databases are not opened by this package. Import old JSON explicitly into a JSON-codec directory.

Quick start​

import cypherlite

# Open an in-memory database
db = cypherlite.connect(":memory:")

# Create nodes
db.execute("CREATE (p:Person {name: $name, age: $age})", {"name": "Alice", "age": 30})
db.execute("CREATE (p:Person {name: $name, age: $age})", {"name": "Bob", "age": 28})

# Create a relationship
db.execute(
    "MATCH (a:Person {name: 'Alice'}), (b:Person {name: 'Bob'}) "
    "CREATE (a)-[:FRIENDS_WITH {since: 2020}]->(b)"
)

# Query the graph
cursor = db.execute("MATCH (p:Person)-[:FRIENDS_WITH]->(friend) RETURN p.name, friend.name")
for row in cursor:
    print(f"{row['p.name']} -> {row['friend.name']}")

db.close()

Module-level functions​

connect​

cypherlite.connect(database: str = ":memory:") -> Connection

Open a connection to a CypherLite database. Pass a directory path for a persistent database, or ":memory:" for an in-memory database. Raises OperationalError if the database cannot be opened.

# In-memory
db = cypherlite.connect(":memory:")

# Persistent directory (manifest + snapshot + wal/)
db = cypherlite.connect("mydata")

Connection​

A connection to a CypherLite database backed by the in-process Database engine. Commits are durable in the WAL before execute() returns; flush() requests a checkpoint.

Methods​

MethodSignatureDescription
execute(query, params=None) -> CursorExecute a Cypher query
executemany(query, params_list) -> CursorExecute a query for each parameter set
flush() -> NoneCheckpoint and recycle eligible WAL (no-op in-memory)
close() -> NoneClose; persistent handles checkpoint on final drop

Properties​

PropertyTypeDescription
closedboolWhether the connection is closed

Context manager​

Connection supports the with statement. The connection is closed automatically on exit.

with cypherlite.connect(":memory:") as db:
    db.execute("CREATE (:Person {name: 'Alice'})")
    cursor = db.execute("MATCH (p:Person) RETURN p.name")
    print(cursor.fetchone())
# Connection is closed here

execute​

Connection.execute(query: str, params: dict = None) -> Cursor

Execute a Cypher query and return a Cursor with the results.

Parameters are passed as a dictionary and referenced with $name in the query:

cursor = db.execute(
    "MATCH (p:Person) WHERE p.age > $min_age RETURN p.name, p.age",
    {"min_age": 25}
)

Supported parameter value types: None, bool, int, float, str, list, dict (nested values allowed).

executemany​

Connection.executemany(query: str, params_list: list[dict]) -> Cursor

Execute a query once for each parameter dictionary in the list. Returns the cursor from the last execution.

db.executemany(
    "CREATE (:Person {name: $name})",
    [{"name": "Alice"}, {"name": "Bob"}, {"name": "Charlie"}]
)

Cursor​

Represents the result of a query execution. Cursors are returned by Connection.execute() with all rows fully materialized.

Properties​

PropertyTypeDescription
columnslist[str]Column names from the RETURN clause
statsdict[str, int]Mutation statistics
rowcountintNumber of rows, or -1 for write-only queries
descriptionlist[tuple]DB-API 2.0 compatible column description

Methods​

MethodSignatureDescription
fetchone() -> dict | NoneFetch the next row, or None if exhausted
fetchmany(size=1) -> list[dict]Fetch up to size rows
fetchall() -> list[dict]Fetch all remaining rows
close() -> NoneClose the cursor (no-op)

Iteration​

Cursors support for loops and len():

cursor = db.execute("MATCH (n) RETURN n.name")
for row in cursor:
    print(row["n.name"])

print(f"{len(cursor)} rows")

Row format​

Each row is a Python dictionary mapping column names to values:

cursor = db.execute("MATCH (p:Person) RETURN p.name, p.age")
row = cursor.fetchone()
# row == {"p.name": "Alice", "p.age": 30}

Use AS aliases for shorter keys:

cursor = db.execute("MATCH (p:Person) RETURN p.name AS name, p.age AS age")
row = cursor.fetchone()
# row == {"name": "Alice", "age": 30}

Nodes are returned as dicts with a _labels key plus their properties; relationships as dicts with a _type key; paths as {"nodes": [...], "relationships": [...]}.

Stats​

The stats property returns mutation statistics as a dictionary:

cursor = db.execute("CREATE (:Person {name: 'Alice', age: 30})")
print(cursor.stats)
# {"nodes_created": 1, "properties_set": 2, "labels_added": 1, ...}

Available stat keys (always present, zero-padded): nodes_created, nodes_deleted, relationships_created, relationships_deleted, properties_set, labels_added, labels_removed.

Exceptions​

All exceptions inherit from CypherLiteError and follow PEP 249 (DB-API 2.0) conventions:

ExceptionDescription
CypherLiteErrorBase exception for all CypherLite errors
InterfaceErrorDatabase interface error (native module communication)
OperationalErrorQuery execution or connection error (syntax error, constraint violation, failure to open database)
ProgrammingErrorProgramming mistake (using a closed connection)
import cypherlite

db = cypherlite.connect(":memory:")
try:
    db.execute("INVALID SYNTAX")
except cypherlite.OperationalError as e:
    print(f"Query failed: {e}")

# Connection still works after an error
print(db.execute("RETURN 42 AS answer").fetchone())  # {"answer": 42}

Native Database API​

For lower-level access — including Arrow interop — use the native Database class directly. This is the class Connection wraps.

from cypherlite import Database

db = Database()          # in-memory (same as Database(":memory:"))
db = Database("graph")   # persistent directory + WAL

Methods​

MethodSignatureDescription
execute(query, params=None) -> QueryResultExecute a Cypher query
execute_arrow(query, params=None) -> bytesExecute and return Arrow IPC stream bytes
flush() -> NoneCheckpoint and recycle eligible WAL
close() -> NoneClose the native handle
reset() -> NoneReopen the same path (in-memory: empty database; directory: reload)
node_count() -> intNumber of nodes
relationship_count() -> intNumber of relationships
labels() -> list[str]All node labels
relationship_types() -> list[str]All relationship types

Errors are raised as RuntimeError (the Connection wrapper translates them into the DB-API exception hierarchy).

QueryResult​

PropertyTypeDescription
columnslist[str]Column names
datalist[dict]Rows as dictionaries
statsdict[str, int]Mutation statistics (only non-zero counters present)
from cypherlite import Database

db = Database()
result = db.execute("CREATE (:Person {name: 'Alice', age: 30})")
print(result.stats)  # {'nodes_created': 1, 'properties_set': 2, 'labels_added': 1}

result = db.execute("MATCH (n:Person) RETURN n.name AS name, n.age AS age")
print(result.columns)  # ['name', 'age']
print(result.data)     # [{'name': 'Alice', 'age': 30}]

Arrow interop​

execute_arrow() returns results as Arrow IPC stream bytes, enabling zero-copy transfer to PyArrow, Pandas, or Polars:

from cypherlite import Database
import pyarrow as pa

db = Database()
db.execute("CREATE (:Person {name: 'Alice', age: 30})")
db.execute("CREATE (:Person {name: 'Bob', age: 28})")

buf = db.execute_arrow("MATCH (n:Person) RETURN n.name AS name, n.age AS age")
table = pa.ipc.open_stream(buf).read_all()
df = table.to_pandas()
print(df)
#     name  age
# 0  Alice   30
# 1    Bob   28

With Polars:

import polars as pl
df = pl.from_arrow(pa.ipc.open_stream(buf).read_all())

Examples​

Persistent database​

import cypherlite

# Create and populate
db = cypherlite.connect("friends")
db.execute("CREATE (:Person {name: 'Alice'})")
db.execute("CREATE (:Person {name: 'Bob'})")
db.execute(
    "MATCH (a:Person {name: 'Alice'}), (b:Person {name: 'Bob'}) "
    "CREATE (a)-[:KNOWS]->(b)"
)
db.close()  # commits were WAL-durable; close checkpoints

# Reopen later
db = cypherlite.connect("friends")
cursor = db.execute("MATCH (a)-[:KNOWS]->(b) RETURN a.name, b.name")
print(cursor.fetchall())
db.close()

Vector similarity search​

import cypherlite

db = cypherlite.connect(":memory:")

# Create documents with embeddings
db.execute("""
    CREATE (:Document {
        title: 'Graph Databases',
        embedding: vector([0.1, 0.8, 0.3, 0.5])
    })
""")
db.execute("""
    CREATE (:Document {
        title: 'Relational DBs',
        embedding: vector([0.9, 0.1, 0.4, 0.2])
    })
""")

# Create a vector index
db.execute("""
    CREATE VECTOR INDEX doc_embedding FOR (d:Document) ON (d.embedding)
    OPTIONS {dimensions: 4, similarity: 'cosine'}
""")

# Query similar documents
cursor = db.execute("""
    CALL db.index.vector.queryNodes('doc_embedding', 2, vector([0.1, 0.9, 0.3, 0.4]))
    YIELD node, score
    RETURN node.title, score
    ORDER BY score DESC
""")
for row in cursor:
    print(f"{row['node.title']}: {row['score']:.3f}")

db.close()

Arrow analytics pipeline​

from cypherlite import Database
import pyarrow as pa

db = Database()
for name, age, city in [("Alice", 32, "Portland"), ("Bob", 28, "Seattle"),
                        ("Carol", 35, "Portland")]:
    db.execute("CREATE (:Person {name: $n, age: $a, city: $c})",
               {"n": name, "a": age, "c": city})

buf = db.execute_arrow("MATCH (p:Person) RETURN p.city AS city, p.age AS age")
df = pa.ipc.open_stream(buf).read_all().to_pandas()
print(df.groupby("city")["age"].mean())
