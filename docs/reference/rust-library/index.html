Rust Library Reference

Embed CypherLite with cypherlite::Database (WAL + CypherLite parser). GraphStore / cypherlite-engine is withdrawn (ADR-0052). Python and the C FFI (cypherlite_*) use the same runtime. Bolt language clients use the product C ABI in cypherlite-ffi.

Quick start​

use std::collections::BTreeMap;
use cypherlite::{Database, Value};

let db = Database::open(":memory:").unwrap();
let mut conn = db.connect().unwrap();

conn.query_with_params(
    "CREATE (:Person {name: $name, age: $age})",
    BTreeMap::from([
        ("name".into(), Value::String("Alice".into())),
        ("age".into(), Value::Int(30)),
    ]),
)
.unwrap();

let result = conn.query("MATCH (n:Person) RETURN n.name AS name, n.age AS age").unwrap();
for row in &result.rows {
    println!("{:?}", row);
}

Snapshot codecs​

Persistent URIs are directories. The WAL is always MDBWAL01; the snapshot is one codec per directory (ADR-0050). Empty URI: OpenOptions.snapshot_codec, else CYPHERLITE_SNAPSHOT_FORMAT, else parquet. Existing directories follow manifest.json / files.

use cypherlite::{Database, OpenOptions, SnapshotCodecKind};

// Default: parquet shards + manifest.json + wal/
let parquet = Database::open("./graph").unwrap();
parquet.checkpoint().unwrap();

let json = Database::open_with(
    "./graph-json",
    OpenOptions {
        wal_dir: None,
        checkpoint_interval: None,
        memory_limit: None,
        snapshot_codec: Some(SnapshotCodecKind::Json),
    },
)
.unwrap();
json.checkpoint().unwrap(); // writes graph.json (full GraphData rewrite)

Import a CypherLite GraphData file: copy it to <dir>/graph.json and open with SnapshotCodecKind::Json.

Adding it to your project​

CypherLite's crates are not yet published to crates.io (the workspace is 0.6.1). Until they are, an external project depends on them with a git dependency:

[dependencies]
cypherlite = { git = "https://github.com/neo4j-labs/cypherlite", tag = "v0.6.1" }

Pin tag (or rev) so your build is reproducible; omit it to track the default branch. Once the crates are published, this becomes a plain version dependency:

# after crates.io publication (not yet available)
cypherlite = "0.6.1"
note

The relative-path form used in this repository — cypherlite = { path = "crates/cypherlite" } — only resolves inside the CypherLite workspace. External projects should use the git dependency above.
