Each error relate reports has a stable id, and each id is an anchor on this page: `https://relatedb.ai/docs/reference/errors/#<id>`. A row gives the message pattern as relate prints it, where it is recorded, the cause, the remedy, whether retrying the same statement can succeed, and the CLI exit code. The tables are generated from one data file, so this page and its markdown twin list the same entries.

## Synopsis

On the CLI, a failed statement prints its message on stderr and exits with the :term[exit code]{id=exit-code} of its class. In `--mode envelope`, `--json` and `--jsonl`, it also prints an error object on stdout. The object's `code` is the class, `kind` is the engine's error variant, `retryable` is `true` only for a write-write conflict, and `message` repeats the stderr text.

```bash
relate --mode envelope 'RETURN $x AS x'
```

The first line of the output is stderr, the second is stdout:

```text
semantic error: ParameterMissing: Expected parameter(s): x
{"error":{"code":"validation_error","exit_code":6,"kind":"semantic","message":"semantic error: ParameterMissing: Expected parameter(s): x","retryable":false}}
```

A syntax error adds `column` and `source`, so a caller can point at the failing token without parsing the message:

```text
syntax error: parse error: expected RightParen, got "RETURN" (RETURN)
  MATCH (n RETURN n
           ^
{"error":{"code":"validation_error","column":10,"exit_code":6,"kind":"syntax","message":"syntax error: parse error: expected RightParen, got \"RETURN\" (RETURN)   MATCH (n RETURN n            ^","retryable":false,"source":"MATCH (n RETURN n"}}
```

`relate agent-context` prints the exit codes of the installed version:

```text
Exit codes:
  0  success: success, including an empty result
  1  fatal_error: runtime failure: store open or I/O error, capacity limit, query execution failure, internal error
  2  usage_error: unknown flag, bad or missing value, extra positional
  5  conflict: write-write conflict, or the store is locked by another opener
  6  validation_error: the statement is rejected: syntax, semantic or type error
  7  timeout: a statement exceeded --timeout
```

In the tables, a message's `<name>` marks a variable part and `…` is an elision in the source. A dash (—) means the sources do not state the value, or it does not apply to that surface.
