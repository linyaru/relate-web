JavaScript Client

The JavaScript client (clients/javascript, package cypherlite) wraps the product C ABI — it does not invent a parallel protocol. Requires Node 18+ and the FFI library discoverable via CYPHERLITE_LIB or libcypherlite_ffi on the search path.

Install and open​

cd clients/javascript && npm install
const { Database } = require("cypherlite");

const db = Database.open(":memory:");   // or a directory / .cl bundle
const conn = db.connect();

const result = conn.query("MATCH (n:Person) RETURN n.name AS name, n.age AS age");
// result.columns: string[]
// result.rows:    any[][]

API​

CallReturnsNotes
Database.open(uri)Database:memory:, a directory, or a .cl bundle
db.connect()ConnectionOne connection per call
conn.query(cypher, params?){ columns, rows }params is a plain object for cypherlite_query_params
conn.begin() / commit() / rollback()—Explicit transaction; auto-commit otherwise

Write-write conflicts throw Error with message write-write conflict; retry in the caller.

Load-test CLIs​

bin/fraud-loadtest.js and bin/identity-loadtest.js wrap this client. Flags, workload mix, and report JSON are in Dataset suites.

Full contract: docs/api/javascript/spec.md.
