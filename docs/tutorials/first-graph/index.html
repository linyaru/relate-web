Your First Graph

In this tutorial you will build a small graph of people and the movies they've acted in. You will learn how to create nodes, connect them with relationships, and traverse the graph with pattern matching.

Setup​

Start CypherLite:

./cypherlite ./movies

That uses the default parquet snapshot codec (plus WAL). For a human-readable graph.json snapshot, use a new directory:

./cypherlite --snapshot-format json ./movies-json

Do not mix codecs in one directory (ADR-0050). Reopen later without the flag; the codec is stored in manifest.json.

Step 1: Create movie nodes​

CREATE (:Movie {title: 'The Matrix', year: 1999, tagline: 'Welcome to the Real World'});
CREATE (:Movie {title: 'The Matrix Reloaded', year: 2003});
CREATE (:Movie {title: 'Cloud Atlas', year: 2012});

Step 2: Create person nodes​

CREATE (:Person {name: 'Keanu Reeves', born: 1964});
CREATE (:Person {name: 'Carrie-Anne Moss', born: 1967});
CREATE (:Person {name: 'Hugo Weaving', born: 1960});
CREATE (:Person {name: 'Lana Wachowski', born: 1965});
CREATE (:Person {name: 'Tom Hanks', born: 1956});

Step 3: Create relationships​

Connect people to movies with ACTED_IN and DIRECTED relationships:

MATCH (keanu:Person {name: 'Keanu Reeves'}), (matrix:Movie {title: 'The Matrix'})
CREATE (keanu)-[:ACTED_IN {roles: 'Neo'}]->(matrix);

MATCH (carrie:Person {name: 'Carrie-Anne Moss'}), (matrix:Movie {title: 'The Matrix'})
CREATE (carrie)-[:ACTED_IN {roles: 'Trinity'}]->(matrix);

MATCH (hugo:Person {name: 'Hugo Weaving'}), (matrix:Movie {title: 'The Matrix'})
CREATE (hugo)-[:ACTED_IN {roles: 'Agent Smith'}]->(matrix);

MATCH (lana:Person {name: 'Lana Wachowski'}), (matrix:Movie {title: 'The Matrix'})
CREATE (lana)-[:DIRECTED]->(matrix);

MATCH (keanu:Person {name: 'Keanu Reeves'}), (reloaded:Movie {title: 'The Matrix Reloaded'})
CREATE (keanu)-[:ACTED_IN {roles: 'Neo'}]->(reloaded);

MATCH (tom:Person {name: 'Tom Hanks'}), (cloud:Movie {title: 'Cloud Atlas'})
CREATE (tom)-[:ACTED_IN]->(cloud);

MATCH (hugo:Person {name: 'Hugo Weaving'}), (cloud:Movie {title: 'Cloud Atlas'})
CREATE (hugo)-[:ACTED_IN]->(cloud);

Step 4: Query the graph​

Find all actors in The Matrix​

MATCH (p:Person)-[:ACTED_IN]->(m:Movie {title: 'The Matrix'})
RETURN p.name, p.born;
+--------------------+--------+
| p.name             | p.born |
+--------------------+--------+
| "Keanu Reeves"     | 1964   |
| "Carrie-Anne Moss" | 1967   |
| "Hugo Weaving"     | 1960   |
+--------------------+--------+

Find all movies for an actor​

MATCH (p:Person {name: 'Keanu Reeves'})-[:ACTED_IN]->(m:Movie)
RETURN m.title, m.year ORDER BY m.year;

Find who directed The Matrix​

MATCH (d:Person)-[:DIRECTED]->(m:Movie {title: 'The Matrix'})
RETURN d.name;

Find co-actors (people who appeared in the same movie)​

MATCH (p1:Person)-[:ACTED_IN]->(m:Movie)<-[:ACTED_IN]-(p2:Person)
WHERE p1.name <> p2.name
RETURN p1.name, p2.name, m.title;

Count movies per actor​

MATCH (p:Person)-[:ACTED_IN]->(m:Movie)
RETURN p.name, count(m) AS movieCount
ORDER BY movieCount DESC;

Step 5: Update and modify​

Add a property​

MATCH (m:Movie {title: 'The Matrix'})
SET m.rating = 8.7;

Add a label​

MATCH (m:Movie {title: 'Cloud Atlas'})
SET m:SciFi;

Remove a property​

MATCH (m:Movie {title: 'The Matrix'})
REMOVE m.tagline;

Step 6: Inspect the graph​

Explore the shape of the graph with ordinary Cypher — introspection dot-commands were withdrawn (ADR-0058). Labels and relationship types come from labels() / type():

MATCH (n) UNWIND labels(n) AS label RETURN DISTINCT label ORDER BY label;
+----------+
| label    |
+----------+
| "Movie"  |
| "Person" |
| "SciFi"  |
+----------+
MATCH ()-[r]->() RETURN DISTINCT type(r) AS relationshipType ORDER BY relationshipType;
+------------------+
| relationshipType |
+------------------+
| "ACTED_IN"       |
| "DIRECTED"       |
+------------------+

And counts come from count():

MATCH (n) RETURN count(n) AS nodes;
+-------+
| nodes |
+-------+
| 8     |
+-------+
MATCH ()-[r]->() RETURN count(r) AS relationships;
+---------------+
| relationships |
+---------------+
| 7             |
+---------------+

What you learned​

  • Creating nodes with labels and properties
  • Creating typed, directed relationships with properties
  • Pattern matching with MATCH
  • Filtering with WHERE
  • Aggregating with count()
  • Modifying the graph with SET and REMOVE
  • Inspecting the graph with labels(), type(), and count()
