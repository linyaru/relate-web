Output Formats

CypherLite renders results in six formats, selected with CLI flags (there is no in-session .mode dot-command — see Dot Commands).

FormatFlagDefault
Table(default)✅
CSV-csv
JSON-json
JSON Lines--mode jsonl
Markdown-markdown
Cypher--mode cypher

Plus -noheader (any format) and the general --mode table\|csv\|json\|jsonl\|markdown\|cypher.

Flags work in one-shot query mode, pipe mode, and the interactive shell.

Table (default)​

cypherlite ./mydata "MATCH (p:Person) RETURN p.name, p.age"
+--------+-------+
| p.name | p.age |
+--------+-------+
| Alice  | 30    |
| Bob    | 28    |
+--------+-------+

CSV​

cypherlite -csv ./mydata "MATCH (p:Person) RETURN p.name, p.age"
p.name,p.age
Alice,30
Bob,28

JSON​

cypherlite -json ./mydata "MATCH (p:Person) RETURN p.name, p.age"
[
  {"p.name": "Alice", "p.age": 30},
  {"p.name": "Bob", "p.age": 28}
]

JSON Lines (JSONL)​

One JSON object per line, suitable for streaming. JSONL has no short flag — use --mode:

cypherlite --mode jsonl ./mydata "MATCH (p:Person) RETURN p.name, p.age"
{"p.name":"Alice","p.age":30}
{"p.name":"Bob","p.age":28}

Markdown​

cypherlite -markdown ./mydata "MATCH (p:Person) RETURN p.name, p.age"
| p.name | p.age |
|--------|-------|
| Alice  | 30    |
| Bob    | 28    |

Cypher​

Renders result values as Cypher literals. Like JSONL, this needs --mode:

cypherlite --mode cypher ./mydata "MATCH (p:Person) RETURN p.name AS name, p.age AS age"
CREATE ({name: 'Alice', age: 30})
CREATE ({name: 'Bob', age: 28})

Note this is a value formatter, not a dump: a returned node column has no Cypher literal form and is omitted (with a // column … omitted comment). For backup, copy the storage directory or .cl file — see Backup and Restore.

Suppress headers​

cypherlite -csv -noheader ./mydata "MATCH (p:Person) RETURN p.name"
Alice
Bob

Redirect output to a file​

There is no .output dot-command. Use the shell's own redirection:

cypherlite -csv ./mydata "MATCH (p:Person) RETURN p.name, p.age" > people.csv
echo "MATCH (n:Person) RETURN n.name" | cypherlite -json ./mydata | jq .
