Every :term[relationship]{id=relationship} has exactly one type, given when it is created: `CREATE (a)-[:WORKS_ON]->(b)`. A pattern matches on it, `-[:WORKS_ON]->`, or on several with `|`, and `type(r)` returns it. A relationship's type cannot be changed in place: `SET r:B` on a relationship fails with `SET labels() requires a node`, so a new type means a new relationship.

```cypher
MATCH (:Person)-[r]->(:Project)
RETURN type(r) AS type, count(*) AS n
```

A dynamic type, `CREATE ()-[:$($type)]->()`, takes the type from a parameter.
