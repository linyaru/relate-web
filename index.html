Cypher queries. Single-file storage. Zero infrastructure.

What's in the Box

Cypher Query Language

Full openCypher support: MATCH, CREATE, MERGE, DELETE, SET, WITH, UNWIND, UNION, FOREACH, LOAD CSV. Pattern matching with variable-length paths.

Vector Search

Store embedding vectors as node properties. Compute cosine and euclidean similarity directly in Cypher with the vector.similarity.* functions, plus vector arithmetic and normalization.

Geospatial

Point type with Haversine distance calculations for geographic coordinates and cartesian distance for 2D points.

Zero Configuration

Single binary, single file. No server, no daemon, no config. Open a .db file and start querying. Like SQLite, but for graphs.

Embeddable Everywhere

Embed the engine directly: a Rust crate, a Python package (PyO3), or any language through the C ABI (JS/Java/Go). Open a store, run Cypher, get structured results — no server required.

CSV Import / Export

LOAD CSV directly in Cypher queries. Dot-commands for .import and .export. Bulk load data from spreadsheets and pipelines.
