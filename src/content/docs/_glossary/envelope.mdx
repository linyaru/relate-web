The envelope is the CLI's machine-readable result: one JSON object per result set, on one line. It holds `columns` and `columnTypes`, the `rows` as objects keyed by column, the planner's `notifications`, and `truncated`. Under a :term[row cap]{id=row-cap} it also holds `rowCap`, with the rows kept and the total. An `EXPLAIN` or `PROFILE` adds the `plan`. Because `columns` is always present, an empty result still says what it would have held.

A failed statement prints an :term[error object]{id=error-object} instead, with the stderr message and the exit code unchanged. Agent mode never changes the envelope's shape.

```bash
relate --mode envelope "UNWIND [1, 2] AS x RETURN x"
```

```text
{"columnTypes":["INTEGER"],"columns":["x"],"notifications":[],"rows":[{"x":1},{"x":2}],"truncated":false}
```
