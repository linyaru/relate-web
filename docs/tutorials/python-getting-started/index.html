Python Quick Start

This tutorial walks you through using CypherLite from Python. By the end, you will be creating nodes, querying a graph, and using parameters — all from a Python script.

Prerequisites​

You need Python 3.9 or later:

python3 --version
# Python 3.9 or later

Install the package​

The cypherlite package is a native extension module — the CypherLite engine runs in-process with your Python code, no separate binary or server required.

The PyPI distribution name is neo4j-cypherlite (cypherlite is taken). After the first tagged publish:

pip install neo4j-cypherlite

From a checkout of this repository (requires the Rust toolchain):

cd crates/cypherlite-python
pip install maturin
maturin develop --release

Connect to a database​

Open an in-memory database:

import cypherlite

db = cypherlite.connect(":memory:")

Create your first node​

Use execute() to run Cypher queries. Mutation stats are available on the returned cursor:

cursor = db.execute("CREATE (:Person {name: 'Alice', age: 30})")
print(cursor.stats["nodes_created"])
1

Add more data​

db.execute("CREATE (:Person {name: 'Bob', age: 28})")
db.execute(
    "MATCH (a:Person {name: 'Alice'}), (b:Person {name: 'Bob'}) "
    "CREATE (a)-[:FRIENDS_WITH {since: 2020}]->(b)"
)

Query the graph​

execute() returns a cursor that you can iterate over. Each row is a dictionary:

cursor = db.execute("MATCH (p:Person) RETURN p.name, p.age ORDER BY p.name")
for row in cursor:
    print(row["p.name"], row["p.age"])
Alice 30
Bob 28

Use parameters​

Pass parameters as a dictionary. Reference them with $name in the query:

cursor = db.execute(
    "MATCH (p:Person) WHERE p.age > $min_age RETURN p.name",
    {"min_age": 29}
)
print(cursor.fetchone())
{'p.name': 'Alice'}

Check mutation stats​

Every cursor has a stats dictionary showing what the query changed:

cursor = db.execute("CREATE (:Movie {title: 'The Matrix', year: 1999})")
print(cursor.stats)
{'nodes_created': 1, 'properties_set': 2, 'labels_added': 1, ...}

Use a context manager​

The with statement automatically closes the connection when done:

with cypherlite.connect(":memory:") as db:
    db.execute("CREATE (:Test {value: 42})")
    cursor = db.execute("MATCH (t:Test) RETURN t.value")
    print(cursor.fetchone())
# Connection is closed automatically
{'t.value': 42}

Use a persistent database​

Pass a directory path instead of ":memory:" to persist data across sessions. Python uses CypherLite's WAL plus snapshot codec (Parquet by default).

# First session
db = cypherlite.connect("mydata")
db.execute("CREATE (:Person {name: 'Alice'})")
db.close()

# Later session
db = cypherlite.connect("mydata")
cursor = db.execute("MATCH (p:Person) RETURN p.name")
print(cursor.fetchall())
db.close()
[{'p.name': 'Alice'}]

Set CYPHERLITE_SNAPSHOT_FORMAT=json before opening a new directory to use GraphData graph.json instead of Parquet. Existing single-file GraphStore JSON requires explicit import.

Bonus: zero-copy DataFrames with Arrow​

The native Database class adds execute_arrow(), which returns results as Arrow IPC bytes for zero-copy transfer to Pandas or Polars:

from cypherlite import Database
import pyarrow as pa

db = Database()
db.execute("CREATE (:Person {name: 'Alice', age: 30})")
db.execute("CREATE (:Person {name: 'Bob', age: 28})")

buf = db.execute_arrow("MATCH (p:Person) RETURN p.name AS name, p.age AS age")
df = pa.ipc.open_stream(buf).read_all().to_pandas()
print(df)
    name  age
0  Alice   30
1    Bob   28

Clean up​

db.close()
